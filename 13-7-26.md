## Topics Covered
No theoretical topics were covered during this training session. The session focused on practical learning and creating a project using Docker.

## Practical Session
The instructor taught us how to create and run a project using Docker. We learned about creating a Dockerfile, which contains instructions for building a Docker image, and how to use that image to create and run a container. The instructor explained how Docker helps package an application along with its required dependencies so that it can run consistently across different environments. We also learned the basic workflow of building an image and running a container to execute the project.

## Learning Outcomes
- Learned the basic concepts of Docker and containerization.
- Understood the purpose of a Dockerfile and Docker image.
- Learned how to build a Docker image and run a container.
- Understood how Docker packages applications with their dependencies.
- Gained practical knowledge of running projects in an isolated and consistent environment.
