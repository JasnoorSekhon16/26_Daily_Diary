## Topics Covered
No theoretical topics were covered during this training session. The entire session was focused on practical learning and understanding the working of Amazon EC2.

## Practical Session
The instructor taught us how to create and configure a project using Amazon Web Services (AWS) EC2. We learned about launching an EC2 instance, selecting a suitable Amazon Machine Image (AMI), choosing an instance type, and configuring the basic settings required to run a virtual server in the cloud. The instructor also explained how EC2 instances provide computing resources without requiring a physical server. We gained an understanding of how these instances can be used to host applications and websites.

## Learning Outcomes
- Learned about Amazon EC2 and its role in cloud computing.
- Understood the process of launching and configuring an EC2 instance.
- Gained knowledge of AMIs and instance types.
- Understood how virtual servers provide computing resources over the cloud.
- Developed practical knowledge of using AWS EC2 for deploying and running projects.
